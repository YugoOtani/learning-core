# UIの好み

更新日：2026-10-03
適用範囲：画面構成やユーザー向け文言を考えるときの好み。

## learning-core のホーム画面

- 背景: 学習ツールは「暗記」「理解」「演習」のような学び方の分類に限らず、AtCoderの問題やAIニュースの閲覧など、内容の異なる個別の体験として一覧に並べる。
- ホーム画面の文言は必要な案内に絞る。ユーザーが一人の利用を前提に「あなた向け」と書かず、検索欄や補足、タグ、所要時間など、依頼されていない細かな要素は増やさない。
- ツール一覧では、各体験を伝えるタイトルと短い説明を基本にする。
- 比較用に、最初の案（非採用）を [learning-home-initial-not-preferred.html](../assets/learning-home-initial-not-preferred.html)、修正後の案を [learning-home.html](../assets/learning-home.html) に保存する。

## 根拠

- 2026-10-03、学習アプリのホーム画面例の修正依頼：学習方法別の分類ではなく、AtCoderの問題やAIニュースのような個別ツールを想定。テーマ検索、「あなた向け」の文言、タグ、所要時間、補足説明を削除するよう指定。
